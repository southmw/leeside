## 1. 개요

| 항목 | 결정 |
|---|---|
| 장르 | 3인칭 액션/어드벤처 + 생존 RPG |
| 세계관 | 기후 붕괴로 문명이 무너진 세계 |
| 시점 | 3인칭 숄더뷰, 자유 회전 카메라 |
| 플레이 방식 | 싱글플레이로 먼저 개발하고, 이후 멀티플레이를 추가한다 |
| 플랫폼 | 데스크톱 웹 브라우저 (모바일 미지원) |
| 조작 | 키보드/마우스, 게임패드 |
| 언어 | 영어, 한국어 |
| 아트 스타일 | 로우폴리 (CC0 무료 에셋) |
| 진행 구조 | 샌드박스 + 느슨한 큰 목표 (엔딩 없음) |
| 월드 구조 | 구역 단위. 구역이 출입구로 이어지고 넘어갈 때 로딩 |
| 프로젝트 목적 | 많은 사람이 플레이하는 것. 설치와 가입 없이 무료로 바로 시작 |
| 1회 플레이 길이 | 10~30분 단위로 끊어 할 수 있어야 함 |

### 제목: LEESIDE

| 항목 | 내용 |
|---|---|
| 제목 | LEESIDE |
| 뜻 | lee side. 바람을 등진 쪽, 바람이 닿지 않는 쪽. 폭풍을 피해 숨을 곳을 찾는 이 게임의 핵심 행동을 가리킨다 |
| 표기 | 영어와 한국어 모두 로마자 `LEESIDE`를 그대로 쓴다. 한글로 읽을 때는 "리사이드" |
| 한국어 부제 | 바람이 닿지 않는 곳 |
| 영어 한 줄 소개 | The weather is your greatest enemy. |

정한 기준:

- 최근 생존 게임의 히트작은 짧은 한 단어 또는 합성어 제목이 많다(Valheim, Palworld, Windrose, StarRupture, Stormforge).
- `Storm`, `Dust`가 들어간 제목은 이미 많아 묻히기 쉽다(Dustward, Dustwind, Stormforge, StormEdge, Stormbound). 그래서 날씨를 직접 말하지 않고 "피할 곳"을 가리키는 낱말을 골랐다.
- 검색으로 확인한 범위에서 같은 제목의 게임은 찾지 못했다. 먼저 검토한 Dustward(같은 장르의 Steam 게임)와 Weatherbound(itch.io 게임)는 이미 쓰이고 있어 제외했다.

한계: 웹 검색으로 확인했을 뿐 상표 조사는 하지 않았다. 또 Leeside는 아일랜드 코크 지역의 별칭이기도 해서 검색 결과에서 지명과 섞일 수 있다. 정식 공개 전에 다시 확인한다.

### 한 줄 소개
날씨가 가장 큰 적이 된 세계에서, 폐허를 뒤져 살아남고 버려진 대피소를 되살려 나가는 게임.

### 설계 기둥
기능을 넣을지 뺄지 판단할 때의 기준이다.

1. **날씨가 가장 큰 적** — 폭염, 모래폭풍, 한파가 언제 나갈지, 어디까지 갈지를 결정한다. 적보다 하늘을 먼저 본다.
2. **수색의 긴장감** — 가방은 좁고 날씨는 곧 바뀐다. "더 뒤질까, 돌아갈까"를 계속 고민하게 만든다.
3. **주운 것이 곧 힘** — 성장은 레벨보다 제작한 장비와 복구한 시설에서 온다.
4. **짧게 해도 남는 것** — 10분만 해도 재료 하나, 제작 하나는 진전이 있어야 한다.

## 2. 세계관

수십 년에 걸친 기후 붕괴로 지역마다 서로 다른 재앙이 자리 잡았다. 어떤 곳은 비가 오지 않고, 어떤 곳은 물에 잠겼고, 어떤 곳은 겨울이 끝나지 않는다. 국가와 도시는 기능을 잃었고, 남은 사람들은 흩어져 살아간다.

플레이어는 버려진 **대피소**를 발견한 생존자다. 대피소의 시설은 모두 멈춰 있고, 되살리는 데 필요한 부품은 각 지역의 핵심 시설에 남아 있다. 그 시설들은 약탈자 무리가 차지하고 있다.

- 이야기는 대사나 컷신 없이 **장소와 남겨진 물건**으로 전달한다(환경 서사).
- 괴물이 아니라 **기후와 굶주림**이 위협의 근원이다. 변종 생물은 재앙에 적응해 변한 동물이며 소수만 등장한다.

## 3. 핵심 루프

```
        ┌───────────────────────────────────────────────────┐
        ▼                                                   │
  대피소에서 준비 → 날씨 확인 → 탐험 → 수색 → 전투 → 귀환 → 제작/복구
  (복장·물·식량)                    │
                                   └─ 사망 시: 가방을 떨어뜨리고 대피소에서 부활
```

| 단위 | 내용 |
|---|---|
| 분 단위 | 이동 → 컨테이너 수색 → 적 조우 → 전투 또는 회피 → 체온 관리 |
| 세션 단위 | 날씨가 괜찮은 시간대에 출발 → 한 지역 수색 → 날씨가 나빠지기 전에 귀환 → 제작 |
| 장기 | 지역 핵심 시설 탈환 → 대피소 시설 복구 → 새 제작 단계와 새 지역 개방 |

## 4. 큰 목표: 대피소 복구와 지역 개척

정해진 엔딩은 없다. 대신 **대피소 시설을 하나씩 되살리는 것**이 게임 전체의 방향을 잡아 준다. 시설을 복구하려면 지역의 핵심 시설에서만 나오는 부품이 필요하고, 그 시설은 약탈자 두목이 지키고 있다.

| 순서 | 지역 | 핵심 시설 | 복구되는 대피소 시설 | 복구 효과 |
|---|---|---|---|---|
| 1 | 가뭄 평원 | 양수장 | 정수 시설 | 대피소에서 물을 무제한 확보. 침수 도시로 가는 길 개방 |
| 2 | 침수 도시 | 변전소 | 발전기 | 고급 작업대 가동(총기 제작 가능). 한파 지대로 가는 길 개방 |
| 3 | 한파 지대 | 기상 관측소 | 온실과 날씨 예보 | 식량 자급. 날씨를 미리 알 수 있음 |

- 각 단계는 **핵심 부품**(두목 처치로 획득) + **일반 재료 다량**(파밍으로 수집)을 요구한다. 전투와 파밍이 한 목표로 묶인다.
- 복구 효과는 그 지역의 생존 압박을 풀어 주는 방향으로 설계한다(가뭄 평원을 넘으면 물 걱정이 줄어든다).
- 세 시설을 모두 복구한 뒤에도 게임은 계속된다. 이후 확장으로 새 지역과 시설을 추가할 수 있다.

## 6. 전투

### 6.1 근접 전투 (기본)
- **약공격**: 연속 입력으로 최대 3단 콤보. 타격마다 스태미나 소모.
- **구르기**: 짧은 무적 시간이 있는 회피. 스태미나 소모가 크다.
- **경직**: 맞으면 짧게 멈춘다. 적도 마찬가지여서 공격 타이밍이 중요하다.
- 스태미나가 바닥나면 공격과 회피를 못 하므로, 무작정 누르는 플레이는 통하지 않게 한다.
- 체온이 나쁘면 스태미나가 불리해진다(7장). 날씨가 전투 난이도에 직접 영향을 준다.

### 6.2 원거리 전투: 활에서 총기로

| 단계 | 무기 | 해금 조건 | 특징 |
|---|---|---|---|
| 초반 | 활 | 작업대 | 화살을 제작하고 일부 회수 가능. 조용함. 당기는 시간이 필요 |
| 후반 | 총기 (권총, 산탄총 등) | 고급 작업대 (발전기 복구 후) | 강력하고 빠름. 탄약 제작 비용이 높고 소리가 주변 적을 끌어들임 |

- 원거리 무기는 근접을 대체하지 않는다. 탄약이 귀해서 **위급할 때 쓰는 수단**으로 둔다.
- 총기는 발전기를 복구해야 만들 수 있다. 큰 목표를 달성한 보상이 전투에서 체감되게 한다.
- 게임패드로 조준할 때는 약한 조준 보조를 넣는다.

### 6.3 피해 계산
```
최종 피해 = 무기 공격력 × 콤보 배율 − 대상 방어력   (최소 1)
```
단순하게 시작하고, 약점 부위·치명타 등은 필요해질 때 추가한다.

### 6.4 적

| 분류 | 종류 | 행동 | 역할 |
|---|---|---|---|
| 약탈자 | 근접형 | 발견하면 접근해 근접 공격 | 기본 적. 장비와 재료를 떨어뜨림 |
| 약탈자 | 사수 | 거리를 두고 활/총으로 공격 | 접근 방법을 고민하게 함 |
| 약탈자 | 두목 | 체력이 많고 고유한 공격 패턴 | 지역 핵심 시설의 보스 |
| 야생동물 | 들개 무리 | 여럿이 둘러싸고 번갈아 공격 | 평지에서의 위협 |
| 야생동물 | 늑대, 곰 | 강한 단일 개체 | 식량·가죽 공급원이자 위험 요소 |
| 야생동물 | 초식동물 | 도망감 | 사냥 대상 |
| 변종 생물 | 지역별 1종 | 지역 환경을 이용한 기습 | 지역의 개성. 희귀 재료 공급원 |

변종 생물 후보(가칭):

| 지역 | 변종 | 특징 |
|---|---|---|
| 가뭄 평원 | 모래잠복체 | 모래 속에 숨어 있다가 가까이 오면 튀어나옴 |
| 침수 도시 | 수변 변종 | 물가에 매복. 물에서는 빠르고 뭍에서는 느림 |
| 한파 지대 | 설원 변종 | 눈보라 속에서만 활동하는 대형 포식자 |

적 AI 상태: `대기 → 순찰 → 추적 → 공격 → 복귀` (+ `경직`, `도주`, `사망`)

- 야생동물은 체력이 줄면 도망간다. 약탈자는 혼자 남으면 물러나기도 한다.
- **적도 날씨의 영향을 받는다.** 폭풍 때는 약탈자가 실내로 들어가고, 포식 동물은 밤에 활발해진다.

## 7. 생존과 환경

### 7.1 허기와 갈증

| 요소 | 내용 |
|---|---|
| 허기 | 실시간 약 40분에 100 → 0 |
| 갈증 | 실시간 약 25분에 100 → 0. 더위 상태에서는 더 빠르게 감소 |
| 회복 | 음식·물 섭취. 오염된 물은 정수하거나 끓여야 안전 |

### 7.2 체온

체온은 가운데가 쾌적하고 양쪽 끝이 위험한 게이지다.

```
 저체온 ◀── 추움 ◀── [ 쾌적 ] ──▶ 더움 ──▶ 열사병
```

| 단계 | 영향 |
|---|---|
| 쾌적 | 불이익 없음 |
| 더움 | 갈증이 빨리 줄고 스태미나 회복이 느려짐 |
| 열사병 | 체력이 서서히 감소, 시야 흐려짐 |
| 추움 | 스태미나 최대치 감소 |
| 저체온 | 체력이 서서히 감소, 이동 속도 감소 |

체온을 움직이는 요인:

| 요인 | 방향 |
|---|---|
| 지역 기온, 시간대(낮/밤) | 지역과 시간에 따라 더위 또는 추위 |
| 날씨(폭염, 한파, 바람) | 기온을 더 극단으로 밀어냄 |
| 젖음(비, 물에 들어감) | 추위 쪽으로. 마를 때까지 지속 |
| 복장 | 보온이 높은 옷은 추위를 막지만 더위에서는 불리. 통풍이 좋은 옷은 그 반대 |
| 열원(모닥불, 난로) | 추위를 해소 |
| 그늘, 실내 | 더위와 바람을 완화 |
| 격한 활동(달리기, 전투) | 더위 쪽으로 약간 |

→ **출발 전에 복장을 고르는 것**이 준비의 핵심이 된다. 한 벌로 모든 지역을 다닐 수 없다.

### 7.3 낮과 밤

| 요소 | 내용 |
|---|---|
| 하루 길이 | 실시간 약 24분 (낮 16분, 밤 8분) |
| 낮 | 시야가 좋음. 가뭄 평원에서는 한낮이 가장 위험 |
| 밤 | 시야가 좁고 기온이 떨어짐. 포식 동물이 활발 |
| 수면 | 대피소 침대에서 시간을 건너뛰고 체력 회복 |

### 7.4 날씨

날씨는 지역마다 다르고, 기온·시야·이동·적 행동에 영향을 준다.

| 지역 | 평상시 | 재난 날씨 | 재난 날씨의 영향 |
|---|---|---|---|
| 가뭄 평원 | 맑고 건조. 낮은 덥고 밤은 추움 | 폭염, 모래폭풍 | 폭염: 급격한 더위. 모래폭풍: 시야가 매우 좁아지고 실외에서 체력 감소 |
| 침수 도시 | 흐리고 습함 | 폭우, 급류 | 폭우: 젖음이 유지되어 추위. 급류: 낮은 길이 잠겨 경로가 바뀜 |
| 한파 지대 | 상시 영하 | 눈보라 | 시야 차단, 급격한 추위. 열원 없이는 버티기 어려움 |

- **예고**: 재난 날씨는 오기 1~2분 전에 하늘 색, 바람 소리, 지평선의 변화로 알 수 있다. 화면 표시보다 풍경으로 먼저 알린다.
- **대피**: 건물 안, 동굴, 직접 만든 임시 은신처에서 피할 수 있다. "지금 어디로 피할 수 있는가"를 늘 염두에 두게 한다.
- **기회**: 재난 날씨는 위험만은 아니다. 모래폭풍 중에는 약탈자가 실내로 들어가 야외 경계가 비고, 폭풍이 지나가면 묻혀 있던 물건이 드러난다.

### 7.5 휴대 생존 도구

| 도구 | 효과 |
|---|---|
| 모닥불 | 열원, 조리, 물 끓이기. 재료를 써서 어디든 설치 |
| 임시 은신처 | 재난 날씨를 피할 수 있는 간이 천막 |
| 물통 | 물을 담아 다님. 용량 업그레이드 가능 |
| 횃불 | 밤 시야 확보, 약한 열원 |

질병, 부상 부위, 방사능은 다루지 않는다(필요하면 이후 검토).

## 8. 아이템과 파밍

### 8.1 아이템 분류

| 분류 | 예시 | 비고 |
|---|---|---|
| 근접 무기 | 쇠파이프, 손도끼, 마체테 | 내구도 있음. 빠른 사용 슬롯에 등록 가능 (누르면 바꿔 듦) |
| 원거리 무기 | 활, 권총, 산탄총 | 내구도 있음, 탄약 필요. 빠른 사용 슬롯에 등록 가능 (누르면 바꿔 듦) |
| 복장 | 방한 외투, 통풍 셔츠, 방진 마스크 | 부위: 머리 / 몸통 / 다리. 방어력 + 보온 + 통풍 수치 |
| 소모품 | 통조림, 정수한 물, 붕대 | 빠른 사용 슬롯에 등록 가능 (누르면 사용) |
| 재료 | 고철, 천, 나무, 테이프, 가죽 | 제작에 사용, 겹쳐 쌓임 |
| 탄약 | 화살, 총알 | 겹쳐 쌓임 |
| 도구 | 곡괭이, 쇠지레, 물통 | 채집 속도, 잠긴 컨테이너 개방 |
| 핵심 부품 | 펌프 부품, 변압기 부품 | 대피소 복구 전용. 두목에게서 획득 |

### 8.2 인벤토리
- 가방 20칸(초기값), 무게 제한 없음. 칸 수만으로 압박을 준다.
- 재료·소모품·탄약은 한 칸에 겹쳐 쌓인다.
- 가방 업그레이드로 칸 수를 늘린다.
- 대피소 보관함은 가방과 별도로 넉넉하게 제공한다.
- 복장은 갈아입을 여벌을 가방에 넣어 다닐 수 있다. 가방 칸과 체온 대비 사이의 선택이 생긴다.

### 8.3 획득 경로
- **컨테이너**: 폐허의 상자, 사물함, 자동차 트렁크. 장소 종류에 따라 나오는 물건이 다르다(주유소 → 연료·공구, 약국 → 의약품).
- **적 처치**: 약탈자는 장비와 재료, 동물은 고기와 가죽, 변종 생물은 희귀 재료.
- **채집**: 나무, 돌, 고철 더미, 식물, 물(우물·웅덩이).
- **사냥**: 초식동물을 잡아 식량과 가죽 확보.

### 8.4 등급
일반 / 고급 / 희귀 3단계로 시작한다. 등급이 높을수록 기본 수치가 높다.

## 9. 크래프팅

### 9.1 설비 티어

| 티어 | 설비 | 조건 | 만들 수 있는 것 |
|---|---|---|---|
| 0 | 맨손 | 없음 | 붕대, 횃불, 모닥불, 조잡한 무기 |
| 1 | 작업대 | 재료로 제작 | 근접 무기, 활과 화살, 기본 복장, 도구, 임시 은신처 |
| 2 | 고급 작업대 | 발전기 복구 | 총기와 탄약, 고급 복장, 장비 강화 |

설비 티어가 게임 진행도와 맞물린다. 티어 2는 침수 도시의 변전소를 탈환해야 열린다.

### 9.2 제작 흐름
1. 레시피는 처음부터 일부 공개, 나머지는 설계도를 줍거나 레벨업으로 해금
2. 설비 근처에서 제작 화면 열기 (맨손 제작은 어디서나)
3. 재료가 충분한 레시피를 선택하면 즉시 제작 (대기 시간 없음으로 시작)

### 9.3 조리와 정수
- 모닥불에서 날고기를 익히고 오염된 물을 끓인다.
- 날것을 먹거나 오염된 물을 마시면 회복량이 적고 체력이 줄어든다.

### 9.4 수리와 강화
- 무기·복장은 사용하면 내구도가 닳고, 재료로 수리한다.
- 강화는 티어 2에서 열린다.

## 10. 성장

- **경험치**: 적 처치, 새 장소 발견, 제작, 시설 복구로 획득
- **레벨업**: 체력·스태미나가 소폭 오르고 퍽 포인트 1개 획득
- **퍽**: 전투 / 생존 / 제작 세 갈래. 예) 스태미나 소모 감소, 더위·추위 내성, 제작 시 재료 절약
- 능력치 숫자보다 **장비와 대피소 시설이 성장의 주된 축**이 되도록 레벨 보너스는 작게 잡는다.

## 11. 월드

### 11.1 구조

월드는 **지역 → 구역** 두 단계로 나뉜다. 지역은 기후가 같은 큰 단위(가뭄 평원 등)이고, 구역은 한 번에 불러오는 맵 하나다.

```
                    ┌─ 묻힌 마을 ──┐
대피소 ─ 마른 강바닥 ┤              ├─ 양수장 ─ (침수 도시로)
                    └─ 주유소 길목 ┘
```

| 항목 | 내용 |
|---|---|
| 구역 크기 | 한 변 300~400m. 끝에서 끝까지 달려서 1~2분 |
| 구역 사이 이동 | 구역 가장자리의 출입구(길, 협곡, 터널)로 걸어서 넘어감. 넘어갈 때 짧은 로딩 |
| 구역 배치 | 지형과 건물은 고정. 모든 플레이어가 같은 지도를 가진다 |
| 날씨 | 같은 지역의 구역은 날씨를 공유한다. 구역을 넘어가도 폭풍은 이어진다 |
| 지역 사이 | 자연 장벽(말라붙은 협곡, 무너진 다리)으로 막혀 있고, 대피소 시설을 복구하면 넘어갈 수단이 생긴다 |

구역이 고정되어 있으므로 **길을 익히는 것이 실력**이 된다. 어느 건물이 대피하기 좋은지, 어느 길이 빠른지를 아는 플레이어가 더 멀리 간다.

### 11.2 내용물 재생성

지형과 건물은 그대로지만 안에 든 것은 다시 채워진다. 같은 구역을 여러 번 수색할 이유를 만든다.

| 대상 | 재생성 |
|---|---|
| 컨테이너 내용물, 채집 자원 | 게임 내 3일마다. 내용물은 매번 다시 뽑는다 |
| 일반 적 | 게임 내 3일마다. 배치 위치는 몇 가지 후보 중에서 바뀐다 |
| 두목, 핵심 부품 | 재생성하지 않는다. 두목이 쓰러진 시설에는 약한 잔당만 남는다 |
| 플레이어가 설치한 것, 떨어뜨린 가방 | 사라지지 않는다 |

재난 날씨가 지나간 직후에는 묻혀 있던 물건이 드러나는 식으로 일부 내용물이 추가된다.

### 11.3 빠른 이동

구역마다 **이동 거점**(안전 가옥, 정비된 야영지)이 하나씩 있다. 걸어가서 발견하면 활성화된다.

- 대피소와 활성화된 이동 거점 사이를 바로 오갈 수 있다. 거점까지는 걸어가야 한다.
- 이동하면 거리에 따라 게임 내 시간이 흐르고 허기와 갈증이 줄어든다.
- **재난 날씨 중에는 빠른 이동을 쓸 수 없다.** 폭풍이 오면 거점까지 뛰어가도 소용없고 그 자리에서 버텨야 한다. "날씨가 나빠지기 전에 돌아간다"는 긴장을 지키기 위한 규칙이다.
- 적에게 쫓기는 중에도 쓸 수 없다.

### 11.4 지역

| 지역 | 풍경 | 생존 규칙 | 주요 자원 | 위험도 | 도입 시점 |
|---|---|---|---|---|---|
| 가뭄 평원 | 갈라진 땅, 말라붙은 강바닥, 모래에 반쯤 묻힌 마을 | 물이 귀함. 한낮의 더위와 밤의 추위 | 고철, 천, 마른 나무 | 낮음 | 수직 슬라이스 |
| 침수 도시 | 물에 잠긴 저층, 옥상과 고가도로로 이어진 길 | 젖으면 추워짐. 물은 많지만 오염됨 | 전자 부품, 의약품, 공구 | 중간 | 이후 확장 |
| 한파 지대 | 눈 덮인 산지와 얼어붙은 시설 | 열원 없이 오래 못 버팀 | 연료, 가죽, 희귀 부품 | 높음 | 이후 확장 |

침수 도시는 얕은 물을 걸어서 건너는 수준으로 제한한다. 수영과 배는 넣지 않는다.

### 11.5 가뭄 평원의 구역 (가칭)

| 구역 | 주요 장소 | 적 | 위험도 | 역할 |
|---|---|---|---|---|
| 마른 강바닥 | 버려진 차량 행렬, 야영지 흔적, 폐가 | 들개 무리 | 낮음 | 시작 구역. 기본 재료와 물 |
| 묻힌 마을 | 모래에 반쯤 묻힌 주택가, 마른 우물 | 약탈자(근접), 모래잠복체 | 중간 | 천, 생활용품, 복장 |
| 주유소 길목 | 주유소, 농가, 도로 | 약탈자(근접, 사수) | 중간 | 고철, 공구, 연료 |
| 양수장 | 양수 시설, 관리동, 약탈자 진지 | 약탈자 다수, 두목 | 높음 | 핵심 시설. 펌프 부품 |

건물 내부는 날씨를 피하는 대피 장소 역할도 한다. 구역마다 대피할 수 있는 건물의 수와 간격이 다르고, 그것이 구역의 난이도를 만든다(양수장으로 가는 길은 대피할 곳이 드물다).

### 11.6 대피소 (거점)
- 시작 지점 근처의 안전한 장소. 날씨의 영향을 받지 않는다.
- 기본 시설: 침대(부활 지점·수면), 보관함, 작업대 자리
- 복구 시설: 정수 시설, 발전기, 온실 (4장)
- 플레이어가 자유롭게 짓는 건설 기능은 이후 확장 항목이다.

### 11.7 사망과 부활
- 사망하면 가방 내용물을 그 자리에 떨어뜨리고 대피소 침대에서 부활한다.
- 장착 중인 장비는 유지한다.
- 떨어뜨린 가방은 다시 죽기 전까지 회수할 수 있다.

## 12. 수직 슬라이스 범위

첫 번째 완성 목표는 **가뭄 평원의 구역 4개와 대피소, 30분 분량의 완결된 플레이**다.

**완결 조건**: 대피소에서 출발해 → 폐허를 수색하고 장비를 제작한 뒤 → 양수장의 두목을 쓰러뜨리고 → 정수 시설을 복구한다.

| 포함 | 제외 (이후 확장) |
|---|---|
| 가뭄 평원 1개 지역 (구역 4개 + 대피소) | 침수 도시, 한파 지대 |
| 이동 거점과 빠른 이동, 내용물 재생성 | 자유 건설 |
| 도입부 (첫 2분) | 스토리 연출 |
| 적: 약탈자(근접, 사수), 들개 무리, 모래잠복체, 두목 1 | 늑대·곰, 다른 지역의 변종 |
| 근접 무기 3종, 활 | 총기 |
| 설비 티어 0~1 | 설비 티어 2, 장비 강화 |
| 허기, 갈증, 체온, 낮/밤 | 젖음 (침수 도시와 함께 도입) |
| 날씨: 폭염, 모래폭풍 | 폭우, 눈보라 |
| 모닥불, 임시 은신처, 조리와 정수 | 날씨 예보 |
| 대피소 + 정수 시설 복구 1단계 | 발전기, 온실 |
| 레벨과 퍽 일부 | 전체 퍽 트리 |
| 저장/불러오기 | 클라우드 저장, NPC, 퀘스트 |

0.1 대비 범위가 늘었다(체온·날씨, 두목, 대피소 복구). 일정이 밀리면 **모래잠복체 → 약탈자 사수 → 임시 은신처** 순으로 뒤로 미룬다. 체온·모래폭풍·두목·정수 시설 복구는 게임의 정체성이므로 빼지 않는다.

## 13. 도입부: 첫 2분

웹 게임은 처음 몇 분 안에 떠나는 사람이 많다. 이 게임의 재미(날씨와의 싸움)는 원래 규칙을 배운 뒤에야 느껴지므로, **가장 강한 장면을 맨 앞에 둔다.**

### 원칙
- 접속하면 타이틀 화면에서 클릭 한 번으로 시작한다. 가입, 선택, 긴 설명이 없다. (브라우저는 사용자가 한 번 누르기 전에는 소리와 마우스 시점 조작을 허용하지 않으므로 이 한 번은 생략할 수 없다.)
- 글로 설명하지 않고 상황으로 가르친다.
- 첫 2분 동안은 죽지 않는다. 위험해 보이지만 실제로는 여유가 있게 조정한다.
- 이미 해 본 플레이어는 건너뛸 수 있다.

### 흐름

| 시간 | 일어나는 일 | 플레이어가 배우는 것 |
|---|---|---|
| 0:00 | 마른 강바닥 한가운데서 시작. 지평선에 모래폭풍의 벽이 보이고 바람 소리가 커진다 | 이 게임의 적은 날씨다 |
| 0:00~0:30 | 이동과 카메라 조작 안내가 한 줄씩 나온다. 멀리 폐가가 보인다 | 조작 |
| 0:30~1:15 | 폐가로 달려가는 길에 버려진 차량이 있다. 트렁크를 열면 물과 천이 나온다 | 수색, 그리고 "더 뒤질까 서두를까"의 고민 |
| 1:15~1:45 | 폭풍이 덮친다. 시야가 좁아지고 체력이 줄기 시작한다. 폐가 안으로 들어가면 멈춘다 | 실내는 안전하다 |
| 1:45~2:00 | 폐가 지하에서 대피소 입구를 발견한다 | 여기가 거점이다 |

### 그 다음 10분
폭풍이 지나가면 밖에 묻혀 있던 물건이 드러나 있다. 주워서 첫 제작(붕대, 조잡한 무기)을 하고, 강바닥을 수색하다가 들개와 처음 싸운다. 여기까지가 "한 번 더 해 볼까"를 결정하는 구간이다.

### 첫 화면까지의 시간
접속 후 10초 안에 타이틀 화면의 시작 버튼을 누를 수 있어야 한다. 도입부에 필요한 에셋만 먼저 받고 나머지는 플레이 중에 받는다([기술 설계서](02-기술설계서.md) 참조).

## 14. 멀티플레이를 염두에 둔 설계 규칙

멀티플레이는 수직 슬라이스 이후에 추가한다. 지금 만들지는 않지만, 나중에 넣을 때 게임 규칙을 뜯어고치지 않도록 다음을 지킨다. 기술적인 대비는 [기술 설계서](02-기술설계서.md) 18장에 있다.

| 싱글플레이에서의 규칙 | 멀티플레이에서 생기는 문제 | 지금 정해 두는 방향 |
|---|---|---|
| 메뉴를 열면 게임이 멈춤 | 여럿이 하면 멈출 수 없음 | 인벤토리와 제작 화면을 열어도 게임은 계속 흐르는 것을 기본으로 한다. 일시정지는 혼자 할 때만 되는 별도 기능으로 둔다 |
| 수면으로 시간을 건너뜀 | 한 사람만 건너뛸 수 없음 | 수면은 "모두 침대에 있을 때만" 건너뛰는 식으로 확장할 수 있게, 수면을 대피소의 기능으로만 둔다 |
| 빠른 이동 시 시간이 흐름 | 한 사람의 이동이 모두의 시간을 바꿈 | 빠른 이동의 비용을 시간 경과에만 의존하지 않게 한다(허기·갈증 소모가 주 비용) |
| 구역을 혼자 넘어감 | 일행이 서로 다른 구역에 있을 수 있음 | 미정. 일행이 함께 넘어가는 방식이 가장 단순하다 |
| 사망 시 대피소에서 부활 | 동료가 살릴 수 있어야 자연스러움 | 사망 전에 "쓰러짐" 단계를 넣을 자리를 남겨 둔다 |
| 컨테이너를 혼자 수색 | 전리품을 누가 갖는가 | 미정 |

날씨는 시드와 게임 시각으로 정해지므로 모든 참가자가 같은 폭풍을 보게 하기 쉽다. "같이 폭풍을 피해 뛰는" 경험은 이 게임의 협동 플레이에서 가장 기대되는 장면이다.

## 15. 설정 메뉴

### 15.1 원칙

- **바꾸는 즉시 적용한다.** 따로 저장 버튼을 두지 않는다. 화면을 다시 불러와야 하는 항목은 그 사실을 알린다.
- **게임 저장과 따로 보관한다.** 설정은 기기에 속하고 게임 진행과 무관하다. 저장을 지워도 설정은 남는다.
- **분류마다 기본값으로 되돌리기**를 둔다.
- **게임 중에 언제든 연다.** Esc로 일시정지 화면을 열고 거기서 들어간다. 혼자 할 때는 게임이 멈추고, 멀티플레이에서는 멈추지 않는다(14장).
- **처음 실행할 때 물어보지 않는다.** 언어는 브라우저 설정을 따르고 그래픽 품질은 자동으로 고른다. 시작을 늦추지 않기 위해서다.
- 모든 화면은 키보드/마우스와 게임패드 양쪽으로 조작할 수 있어야 한다.

### 15.2 항목

"시점"은 그 항목을 넣는 시기다. 시제품의 항목은 [시제품 설계](06-시제품설계.md) 7장에 있다.

**화면**

| 항목 | 선택지 | 시점 |
|---|---|---|
| 그래픽 품질 | 자동 / 낮음 / 중간 / 높음 | 시제품 (낮음/높음만) |
| 전체 화면 | 켜기/끄기 | 시제품 |
| 해상도 배율 | 50~100% | 수직 슬라이스 |
| 그림자 | 끄기 / 낮음 / 높음 | 수직 슬라이스 |
| 후처리 효과 (블룸, 아지랑이) | 켜기/끄기 | 수직 슬라이스 |
| 소품 밀도, 가시거리 | 낮음 / 중간 / 높음 | 수직 슬라이스 |
| 프레임 제한 | 30 / 60 / 제한 없음 | 수직 슬라이스 |
| 시야각 | 50~90° | 수직 슬라이스 |
| FPS 표시 | 켜기/끄기 | 시제품 |

그래픽 품질을 고르면 아래 세부 항목이 한꺼번에 바뀌고, 세부 항목을 따로 고치면 품질 표시가 "사용자 지정"이 된다.

**소리**

| 항목 | 선택지 | 시점 |
|---|---|---|
| 전체 음량 | 0~100% | 시제품 |
| 효과음, 환경음(날씨), 음악 음량 | 각 0~100% | 수직 슬라이스 |
| 창이 가려지면 음소거 | 켜기/끄기 | 수직 슬라이스 |

**조작**

| 항목 | 선택지 | 시점 |
|---|---|---|
| 마우스 감도 | 슬라이더 | 시제품 |
| 상하 반전 | 켜기/끄기 | 시제품 |
| 조작 방법 보기 | 키 배치 그림 | 시제품 |
| 키 설정 변경 | 행동별 키 지정, 중복 경고 | 수직 슬라이스 |
| 게임패드 감도, 상하 반전, 진동 | — | 수직 슬라이스 |
| 달리기 방식 | 누르고 있기 / 한 번 눌러 전환 | 수직 슬라이스 (전투와 함께) |
| 조준 보조 (게임패드) | 끄기 / 약하게 | 수직 슬라이스 (활과 함께) |

**게임**

| 항목 | 선택지 | 시점 |
|---|---|---|
| 언어 | English / 한국어 | 시제품 |
| 안내 문구 표시 | 켜기/끄기 | 수직 슬라이스 |
| 피해 숫자 표시 | 켜기/끄기 | 수직 슬라이스 (전투와 함께) |
| 화면 흔들림 | 끄기 / 약하게 / 보통 | 수직 슬라이스 (전투와 함께) |
| 온도 단위 | 섭씨 / 화씨 | 수직 슬라이스 (기온을 숫자로 보여 줄 경우) |

**접근성**

| 항목 | 선택지 | 시점 |
|---|---|---|
| 글자와 HUD 크기 | 작게 / 보통 / 크게 | 수직 슬라이스 |
| 색에 의존하지 않는 표시 | 체온과 위험 표시에 색 외에 모양과 글자를 함께 씀 (설정이 아니라 기본 설계) | 시제품부터 |
| 화면 번쩍임 줄이기 | 켜기/끄기 | 수직 슬라이스 |
| 누르고 있기를 한 번 누르기로 | 수색 등 길게 누르는 동작을 한 번 누르기로 바꿈 | 수직 슬라이스 |

**저장 데이터**

| 항목 | 내용 | 시점 |
|---|---|---|
| 저장 파일 내보내기 / 가져오기 | 브라우저 데이터를 지워도 진행을 지킬 수 있게 | 수직 슬라이스 (저장과 함께) |
| 진행 초기화 | 확인을 한 번 더 받음 | 수직 슬라이스 |
| 저장 위치 안내 | "이 브라우저에만 저장됩니다"라는 설명 | 수직 슬라이스 |

**정보**

| 항목 | 내용 | 시점 |
|---|---|---|
| 버전 | 빌드 번호 | 시제품 (화면 구석에 표시) |
| 의견 보내기 | 외부 설문 주소 | 시제품 (끝 화면에서) |
| 만든 사람과 에셋 출처 | 무료 에셋의 출처 표기 | 수직 슬라이스 |

### 15.3 넣지 않는 것

| 항목 | 이유 |
|---|---|
| 난이도 선택 | 미정 사항. 수직 슬라이스 이후에 검토 |
| 해상도 직접 지정, 창 모드 선택 | 브라우저에서는 창 크기가 곧 해상도다. 해상도 배율로 대신한다 |
| 수직 동기화 | 브라우저가 관리한다 |
| 계정, 클라우드 저장 | 가입 없이 바로 시작하는 것이 목적이다 |

## 16. 미정 사항

| 항목 | 현재 가정 | 결정 시점 |
|---|---|---|
| 배포와 홍보 (사람들이 이 게임을 어떻게 알게 되는가) | 계획 없음. G1의 공개 테스트를 itch.io와 커뮤니티에 올리는 것까지만 정해짐 | G1 결과를 본 뒤 |
| 멀티플레이의 형태 | 친구끼리 하는 2~4인 협동 (대전 아님) | 수직 슬라이스 이후 |
| 구역 크기와 구역 수 | 한 변 300~400m, 지역당 4개 | 시제품 플레이 테스트 후 |
| 내용물 재생성 주기 | 게임 내 3일 | 파밍 구현 단계에서 조정 |
| 빠른 이동의 비용 | 시간 경과 + 허기·갈증 소모 | 구역 확장 단계 |
| 게임 제목의 상표 확인 | LEESIDE로 정함. 웹 검색만 함 | 정식 공개 전 |
| 지명, 적 이름 | 가칭 사용 | 수직 슬라이스 마감 전 |
| 플레이어 캐릭터 설정 | 이름·배경 없는 생존자 | 수직 슬라이스 이후 |
| 재난 날씨의 발생 빈도 | 게임 내 하루에 0~1회 | 생존 구현 단계에서 조정 |
| 총기 종류와 수 | 권총, 산탄총 2종 | 침수 도시 기획 시 |
| 제작 대기 시간 | 없음(즉시) | 제작 구현 단계 |
| 난이도 선택 | 없음(단일 난이도) | 수직 슬라이스 이후 |
