## 5. 쓰지 않는 것

| 에셋 | 이유 |
|---|---|
| Post-Apocalyptic World (Atomic Realm) | 주유소, 약국, 실내, 돌연변이 식물까지 있어 테마는 가장 잘 맞는다. 하지만 CC0가 아니고 출처 표기와 링크가 필수이며 재배포를 금지한다. CC0 규칙을 바꾸지 않는 한 쓸 수 없다 |
| Universal Base Characters (Quaternius) | 받아 보니 옷을 입히기 위한 바탕 몸이다(속옷 차림, 머리카락 별도). 반실사 스타일에 2048px 텍스처를 써서 로우폴리 단색 방향과 맞지 않고, 무료 판은 6종이 아니라 2종이다. 게임에 넣어 보니 작고 점프 동작이 어색했다 |
| Universal Animation Library 1·2 (Quaternius) | 위 바탕 몸과 뼈대가 같은 애니메이션 모음(무료 판 43개). 지금 쓰는 캐릭터와는 뼈대가 달라 쓸 수 없다. 같은 뼈대의 캐릭터를 쓰게 되면 다시 본다 |
| Kenney의 모델 팩 (Survival Kit, Car Kit, Retro Urban Kit, City Kit) | 2.31에서 Survival Kit과 Car Kit을 강바닥에 적용해 Quaternius와 비교했고, Quaternius가 게임의 스타일에 더 맞아 쓰지 않기로 했다. 차량이 장난감처럼 짧고 통통하다. Kenney의 오디오 팩은 스타일과 무관하므로 후보로 남긴다 |
| CC-BY, CC-BY-SA 소리와 모델 | 출처 표기 의무가 생긴다. CC-BY-SA는 파생물에 같은 라이선스를 요구한다 |

## 6. 들여올 때 지킬 것

- **스타일의 기본 축은 Quaternius다.** 캐릭터, 차량, 바위를 같은 제작자의 팩에서 가져온다. Kenney는 비교해 보고 쓰지 않기로 했다(2.31). KayKit(귀여운 스타일)과 Retro Urban Kit(PS1 느낌)은 섞으면 화면이 어수선해지므로 꼭 필요할 때만 쓴다.
- **Quaternius 무료 판(Standard)은 팩 전체가 아니다.** 팩의 60~70%만 무료이고 나머지는 유료 판에 있다. 소개 페이지의 모델 수는 유료 판 기준일 수 있으니 받아서 확인한다.
- **원본은 `Src/assets-src/`에 두고 커밋하지 않는다.** 게임에 넣는 파일은 변환 스크립트(`Src/scripts/`)로 만들어, 원본만 있으면 다시 만들 수 있게 한다.
- **용량을 줄여서 넣는다.** 받은 glTF는 `gltf-transform` 같은 도구로 압축하고 텍스처 크기를 줄인다. 도구를 설치할 때는 먼저 확인을 받는다(작업 규칙 1).
- **출처를 적는다.** `Src/public/` 아래 `CREDITS.md`에 제작자, 라이선스, 출처를 적는다. CC0라 의무는 아니지만 프로젝트 규칙이다.
- **에셋을 못 받아도 게임이 돌아가게 한다.** 지금 캐릭터 모델이 캡슐로 대체되는 것처럼, 다른 모델도 임시 도형으로 대체한다.

## 7. 결정

2026-11-17에 정했다. 단계 번호는 [시제품 개발 계획](05-시제품개발계획.md)의 것이다.

| 항목 | 결정 | 하는 단계 |
|---|---|---|
| 플레이어 캐릭터 | M2에서 바꿨다. Zombie Apocalypse Kit의 4종(Matt, Lis, Sam, Shaun)을 쓰고 타이틀 화면에서 고른다 | 2.29 (완료) |
| 하늘 방식 | 색 그라데이션으로 칠한 하늘. HDRI(Poly Haven)와 Three.js의 대기 계산 하늘까지 셋을 비교한 뒤 정했다. HDRI는 쓰지 않는다 | 2.2 (완료) |
| 스타일의 기본 축 | **Quaternius.** Kenney 팩과 같은 자리에 번갈아 적용해 보고 정했다 | 2.31 (완료) |
| 나머지 소품 | 차량, 출구의 잔해(컨테이너), 큰 바위를 모델로 바꿨다. 천막과 우물은 맞는 모델이 없어 상자로 남았다 | 2.31 (완료) |
| 차량의 크기 | 팩 안의 사람 대 차 비율을 따른다(길이 6.1~6.7m). 직접 보고 확정 | 2.30 (완료) |

남은 일: 천막과 우물에 쓸 Quaternius 스타일의 모델 찾기. 상자 수색(2.14)의 상자에는 Zombie Apocalypse Kit의 Chest를 쓸 수 있다.
