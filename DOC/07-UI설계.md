배치 그림은 위치와 구성을 보여 주는 개략도다. 그림 속 글자는 영어판 기준이며(한글은 그림의 줄이 맞지 않아서), 실제 화면은 영어와 한국어를 모두 지원한다. 색, 크기, 문구는 초기값이다.

## 1. 원칙

| # | 원칙 | 내용 |
|---|---|---|
| 1 | 풍경이 먼저, 화면 표시는 그다음 | 폭풍은 하늘과 소리로 먼저 알린다. 화면 표시는 그것을 확인해 주는 역할이다 |
| 2 | 게임 화면을 가리지 않는다 | 플레이 중의 표시는 화면 가장자리에 둔다. 가운데는 비운다 |
| 3 | 창을 열어도 게임은 흐른다 | 상자와 가방을 열어도 시간이 간다(멀티플레이 대비). 멈추는 것은 일시정지뿐이다 |
| 4 | 색에만 의존하지 않는다 | 수치마다 아이콘과 글자를 함께 쓴다. 위험은 색과 함께 깜빡임이나 모양으로도 알린다 |
| 5 | 글자는 짧게 | 영어와 한국어의 길이가 달라도 깨지지 않게 한다. 버튼은 가장 긴 문구를 기준으로 폭을 잡는다 |
| 6 | 클릭 한 번으로 시작 | 타이틀 화면에서 한 번 누르면 바로 플레이한다. 가입, 꼭 해야 하는 선택, 긴 설명이 없다. 캐릭터 선택은 이미 하나가 골라져 있어 건너뛸 수 있다 |
| 7 | 키보드만으로도 급한 일은 한다 | 폭풍 속에서 물을 마시거나 상자를 여는 일에 마우스 커서가 필요하지 않게 한다 |

## 2. 화면 흐름

```
접속
  │
  ▼
[타이틀] ──(설정)──▶ [설정] ──▶ [타이틀]
  │ START
  ▼
[게임 화면 (HUD)] ◀────────────────────────────────────────┐
  │                                                        │
  ├─ E (상자 앞)   ──▶ [상자 패널] ──(닫기/멀어짐)──────────┤
  ├─ Tab           ──▶ [가방 창]   ──(Tab/Esc)─────────────┤
  ├─ Esc           ──▶ [일시정지] ──▶ [설정] / [조작 방법] ─┤
  ├─ 구역 출입구   ──▶ [구역 전환] ─────────────────────────┤
  ├─ 대피소 도착   ──▶ [귀환 정산] ──(다음 날)──────────────┤
  ├─ 체력 0        ──▶ [사망] ──(계속하기)─▶ [귀환 정산 없이 다음 날] ──┤
  │                      └─(그만하기)─▶ [타이틀]                       │
  └─ 수리 완료     ──▶ [끝] ──(계속하기)────────────────────┘
                         └─(의견 남기기)─▶ 외부 설문 (새 탭)
```

`?bench`로 접속하면 타이틀 없이 성능 측정이 시작되고 끝나면 [성능 측정 결과]가 나온다.

## 3. 공통 규칙

### 3.1 배치와 크기

| 항목 | 내용 |
|---|---|
| 기준 크기 | 1920×1080에서 설계. 창 높이에 비례해 전체 UI 크기를 조절(배율 = 창 높이 ÷ 1080, 2배에서 멈춤) |
| 최소 지원 크기 | 1280×720. 그보다 작으면 "창을 키워 주세요" 안내 |
| 가장자리 여백 | 24px (기준 크기에서) |
| 넓은 화면 | 울트라와이드에서는 HUD를 가운데 16:9 영역 안에 둔다. 구석 끝까지 벌어지지 않게 |
| 글자 크기 | 본문 16px, 작은 글자 14px 이상, 제목 28px (기준 크기에서) |
| 글꼴 | 기기에 설치된 글꼴. 숫자는 폭이 일정한 숫자 글꼴 설정을 써서 값이 바뀌어도 흔들리지 않게 |

### 3.2 모양

| 항목 | 내용 |
|---|---|
| 패널 | 어두운 반투명 바탕, 얇은 테두리, 모서리 약간 둥글게. 게임 화면 위에서 글자가 읽히게 |
| 강조색 | 모래색 계열 (버튼, 선택 표시, 진행 막대) |
| 경고색 | 주황 (폭풍 예고, 가방 가득 참), 빨강 (체력 위험, 폭풍 도달) |
| 수치 색 | 체력 빨강, 갈증 파랑, 체온은 추위 쪽 파랑·쾌적 흰색·더위 쪽 주황 |
| 움직임 | 창이 뜨고 닫힐 때 0.15초 정도의 짧은 전환. 과한 애니메이션은 쓰지 않음 |

### 3.3 조작

| 상태 | 마우스 | 키보드 |
|---|---|---|
| 플레이 중 | 왼쪽이나 오른쪽 버튼을 누른 채 움직이면 시점 회전(누르는 동안만 커서 숨김), 휠로 카메라 거리 조절 | 이동, 상호작용, 빠른 사용 |
| 상자 패널 | 시점 회전은 그대로(버튼을 누른 채 움직이기). 휠은 물건 선택에 쓰고 카메라 거리는 바꾸지 않음 | 화살표 키/휠로 선택, E 가져가기, F 모두 가져가기 |
| 가방 창, 일시정지, 설정, 정산, 끝 | 커서 표시, 클릭 | Tab/화살표로 이동, Enter 선택, Esc 닫기 |

- 커서는 평소에 항상 보이고, 시점을 돌리려고 마우스 버튼을 누르고 있는 동안에만 숨는다. 그래서 창을 열고 닫을 때 커서를 따로 전환할 필요가 없다. 창이 열려 있는 동안에는 창 위의 클릭이 시점을 돌리지 않게 한다.
- 모든 버튼은 마우스를 올리거나 키보드로 선택했을 때 표시가 달라진다.
- 창에서는 화살표 키와 Tab으로 선택을 옮기고(끝에서 처음으로 돌아감), Enter나 Space로 선택하고, Esc로 닫는다. 창이 열려 있는 동안 이 키들은 게임에 전달되지 않는다(Space로 점프하지 않는다). 창은 한 번에 하나만 열린다.
- 게임패드 조작은 시제품에서 선택 사항이다. 넣는다면 모든 창을 방향 키와 A/B 버튼으로 다룰 수 있어야 한다.

### 3.4 키 배치 (시제품)

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 왼쪽/오른쪽 버튼을 누른 채 이동 | 시점 |

| Space | 점프 |
| E | 상호작용 (상자는 1.5초 누르고 있기, 버린 물건은 한 번 눌러 줍기, 출입구는 한 번 눌러 드나들기), 상자 패널에서 가져가기 |
| F | 상자 패널에서 모두 가져가기 |

| Enter | 가방 창에서 고른 물건 쓰기 |
| X | 가방 창에서 고른 물건 한 개 버리기 |
| Esc | 일시정지, 창 닫기 |
| F3 | 디버그 화면 (개발용) |

### 3.5 아이콘

시제품용 아이콘 18종을 만들어 [icons/](icons/) 폴더에 두었다. [icons/preview.html](icons/preview.html)을 브라우저로 열면 전체를 볼 수 있다.

| 분류 | 아이콘 (파일 이름) |
|---|---|
| 수치 | 체력 `health`, 체온 `temperature`, 갈증 `thirst` |
| 날씨·상태 | 폭풍 `storm`, 경고 `warning`, 대피소 `shelter`, 추위 `cold`, 낮 `day`, 밤 `night` |
| 물건 | 고철 `scrap`, 천 `cloth`, 테이프 `tape`, 물병 `water-bottle`, 붕대 `bandage` |
| 화면 | 가방 `bag`, 떨어뜨린 가방 위치 `marker-bag`, 수색 `search`, 설정 `settings` |

| 규칙 | 내용 |
|---|---|
| 형식 | SVG, 24×24 기준 |
| 모양 | 선으로만 그림. 선 굵기 2, 끝과 모서리를 둥글게 |
| 색 | 파일에 색을 넣지 않고 쓰는 곳의 글자색을 따른다(`currentColor`). 같은 아이콘을 체력은 빨강, 경고는 주황처럼 상황에 맞게 칠할 수 있다 |
| 크기 | 16px까지 줄여도 알아볼 수 있게. 미리 보기에서 24px와 16px로 확인했다 |
| 글자와 함께 | 아이콘만으로 뜻을 전하지 않는다. 수치에는 이름을, 물건에는 개수와 이름을 함께 쓴다 |

- 피해 원인 표시는 `storm`, `cold`, `thirst`를 그대로 쓴다. 나침반의 대피소 표시는 `shelter`를 쓴다.
- 게임에서 쓰는 아이콘은 `Src/src/ui/icons/`에 복사해 두고 코드에 넣어 묶는다(`ui/icons.ts`). 처음에는 `Src/public/assets/icons/`로 옮길 계획이었는데, 그림 파일로 불러오면 글자색을 따르지 못하고 아이콘마다 요청이 생겨서 바꿨다. 원본은 이 폴더에 그대로 두고, 고치면 양쪽을 맞춘다.
- 직접 만든 것이라 출처 표기가 필요 없다.
- 본편에서 물건이 늘면 같은 규칙으로 추가한다. 물건 아이콘이 수십 개가 되면 선 그림만으로는 구분이 어려워지므로 그때 색이 들어간 그림으로 바꾸는 것을 검토한다.

## 4. 타이틀 화면

접속하면 가장 먼저 보이는 화면이다. 뒤에는 게임의 시작 장면(마른 강바닥과 지평선의 폭풍)이 실제로 그려지고 있다.

```
+------------------------------------------------------------------------------+
|                                                          [EN | KO]  [Settings]|
|                                                                              |
|          (live 3D scene: dry riverbed, storm wall on the horizon)            |
|                                                                              |
|                                                                              |
|                              L E E S I D E                                   |
|                    The weather is your greatest enemy.                       |
|                                                                              |
|                              [    START    ]                                 |
|                                 Character                                    |
|                         [Matt | Lis | Sam | Shaun]                           |
|                                                                              |
|                  WASD Move  -  Mouse Look  -  E Search                       |
|                                                                              |
| Prototype v0.1                                        Desktop browser only   |
+------------------------------------------------------------------------------+
```

| 요소 | 내용 |
|---|---|
| 배경 | 시작 장면을 실시간으로 그림. 카메라가 천천히 움직이고 바람 소리는 클릭 전이라 아직 없음 |
| 제목과 한 줄 소개 | `LEESIDE`를 자간을 넓힌 글자로 표시. 로고 그림은 따로 만들지 않고 글자로 시작. 한국어에서는 아래에 부제 "바람이 닿지 않는 곳" |
| START 버튼 | 누르면 소리가 켜지고 도입부가 바로 시작됨. Enter와 Space로도 됨 |
| 캐릭터 선택 | 4명(Matt, Lis, Sam, Shaun) 중 하나. 누르거나 좌우 화살표 키로 바꾸면 뒤 장면의 캐릭터가 바로 바뀐다. 고르기 쉽도록 타이틀에서는 캐릭터가 카메라 쪽을 보고 서 있다. 능력 차이는 없고 겉모습만 다르다. 고른 캐릭터는 브라우저에 기억되어 다음 접속 때 그대로 나온다. 처음에는 Matt |
| 언어 전환 | 영어/한국어. 누르면 즉시 바뀜 |
| 설정 버튼 | 설정 화면으로 |
| 조작 안내 | 핵심 조작 세 가지만 한 줄로 |
| 버전, 안내 | 시제품 표시와 "데스크톱 브라우저 전용" |

### 로딩과의 관계
- 타이틀 화면은 **최소한의 파일만 받으면 바로 뜬다.** 그동안 나머지를 뒤에서 받는다.
- 받는 중에는 START 버튼 자리에 진행 막대를 보여 주고, 다 받으면 버튼으로 바뀐다.
- "접속 후 10초 안에 조작 가능" 목표는 **START 버튼이 눌릴 수 있게 되는 시점** 기준이다.
- 다시 접속한 사람에게도 같은 화면이 나온다. 도입부를 이미 끝낸 기기에서는 START 아래에 "도입부 건너뛰기" 선택이 생긴다.

### 지원하지 않는 환경
모바일 기기나 3D 그래픽을 쓸 수 없는 브라우저에서는 타이틀 대신 안내 문구를 보여 준다("이 게임은 데스크톱 브라우저에서 플레이할 수 있습니다").

## 5. 게임 화면 (HUD)

플레이 중에 항상 보이는 표시다.

```
+------------------------------------------------------------------------------+
| 60 FPS            W . . . . N . . ^ . . E . . . . S               DAY 2      |
|                                                                   07:40      |
|                  +------------------------------------+                      |
|                  | ! STORM APPROACHING   [######----] |      DOOR REPAIR     |
|                  +------------------------------------+      Scrap   6 / 15  |
|                                                              Cloth   3 / 8   |
|                                                              Tape    1 / 3   |
|                                      .                                       |
|                               [E] Search (hold)                              |
|                                                                              |
|              Find shelter before the storm hits.                             |
|                                                                              |
| HP    [########--]                                              [ SHELTERED ]|
| TEMP  [---|#|----]                                             [Tab] Bag 6/8 |
| WATER [######----]              [1 Water 2][2 Band 1][3     ][4     ]        |
+------------------------------------------------------------------------------+
```

| 위치 | 요소 | 내용 |
|---|---|---|
| 위 가운데 | 나침반 | 방위와 함께 대피소 입구(`^`), 떨어뜨린 가방의 방향을 표시. 폭풍으로 시야가 25m일 때 길을 잃지 않게 하는 용도 |
| 위 가운데 아래 | 폭풍 경고 | 예고 단계에서 나타남. 막대가 줄어들며 남은 시간을 보여 줌. 폭풍이 도달하면 빨갛게 바뀌고 "STORM", 잦아들면 사라짐. 평상시에는 없음 |
| 위 오른쪽 | 날짜와 시각 | 생존 일수와 현재 시각. 시각은 10분 단위로 표시. 해 질 무렵에는 주황색, 밤에는 푸른색으로 바뀌고, 색에만 의존하지 않도록 시각 아래에 "해 질 무렵", "밤"이라고 적는다(낮에는 비움) |
| 오른쪽 | 수리 목표 | 재료별 `모은 수 / 필요한 수`. 수리에 넣은 것 기준이며, 가방에 든 것은 괄호로 따로 표시(예: `6 (+3) / 15`) |
| 가운데 | 조준점과 상호작용 안내 | 작은 점. 대상이 있으면 그 아래에 키와 동작을 표시. 누르고 있는 동안 점 둘레에 진행 고리. 세부는 아래 "조준점과 상호작용 안내 (2.12)" |
| 아래 가운데 위 | 안내 문구 | 도입부의 안내와 상황 알림("가방이 가득 찼습니다"). 몇 초 뒤 사라짐 |
| 아래 왼쪽 | 체력, 체온, 갈증 | 아이콘 + 이름 + 막대. 체온은 가운데가 쾌적인 양방향 막대. 위험 구간이면 깜빡임. 체력 막대는 이름과 수치(올림한 정수) 아래의 붉은 막대이고 2.8에서 먼저 만들었다. 체온 막대는 그 아래에 있고 화면의 이름은 "온도"다. 이름과 단계(쾌적, 추움, 저체온) 아래에 가운데 눈금이 있는 막대가 있어 추울수록 푸른 막대가 왼쪽으로 자란다(2.9). 갈증 막대는 맨 아래에 있고 체력 막대와 같은 모양에 물색이다(2.10). 아이콘과 깜빡임은 2.11 |
| 아래 가운데 | 빠른 사용 칸 4개 | 칸마다 누르는 키(1~4), 지정된 물건의 아이콘과 이름, 가방에 든 개수. 세부는 아래 "빠른 사용 칸과 가방 표시" |
| 아래 오른쪽 (대피 중 표시 위) | 가방 표시 | `bag` 아이콘, 여는 키(Tab), 찬 칸 수(`6 / 8`). 가득 차면 주황색. 가방 속은 가방 창(7장)에서 본다 |
| 아래 오른쪽 | 대피 중 표시 | 대피 영역 안에 있을 때만 나타남. 평소에는 어두운 바탕에 밝은 글자이고, 폭풍 중에는 모래색 바탕에 어두운 글자로 바뀌어 더 눈에 띔. 아이콘(`shelter`)은 2.11에서 붙임 |
| 위 왼쪽 | FPS | 설정에서 켰을 때만 |

### 상태에 따른 변화

| 상황 | 화면 변화 |
|---|---|
| 폭풍 예고 | 경고가 나타나고 막대가 줄어듦. 나침반의 대피소 표시가 강조됨 |
| 폭풍 속 실외 | 화면 가장자리가 모래색으로 흐려짐. 체력 막대가 깜빡임 |
| 폭풍 속 실내 | 대피 중 표시가 강조됨. 가장자리 효과 없음 |
| 밤의 추위 | 화면 가장자리가 푸르게 변함. 체온 막대가 왼쪽으로 이동 |
| 체력 30 이하 | 화면 가장자리가 붉어짐 |
| 갈증 20 이하 | 갈증 막대가 깜빡이고 물병이 있으면 빠른 사용 칸이 강조됨 |
| 피해를 입음 | 원인 아이콘이 체력 막대 옆에 잠깐 표시됨 (폭풍, 추위, 갈증) |

"체력이 왜 줄어드는지 알 수 있다"는 확인 항목을 위해 마지막 줄의 원인 표시가 중요하다.

### HUD의 세부 규칙 (2.11)

무엇을 보여 줄지는 순수 함수로 정한다(`src/ui/hudState.ts`). 수치는 초기값이다.

**나침반.** 위 가운데의 띠다. 띠의 가운데가 지금 바라보는 방향이고, 좌우로 90°씩 180°를 보여 준다. 양 끝의 글자가 잘리지 않도록 끝은 띠의 가장자리보다 조금 안쪽에 그린다.

| 요소 | 내용 |
|---|---|
| 방위 | N, E, S, W는 글자로, 그 사이(북동 등)는 짧은 눈금으로 표시. 띠 밖의 방위는 보이지 않음 |
| 가운데 표시 | 띠 가운데 아래의 작은 세모. 바라보는 방향 |
| 대피소 | `shelter` 아이콘. 대피소 입구(폐가 A 안)의 방향에 놓인다. 띠 밖(뒤쪽)이면 가까운 쪽 끝에 붙고 화살표가 붙어 그쪽으로 돌라는 뜻이 된다 |
| 강조 | 폭풍 예고와 폭풍 중에는 대피소 아이콘이 모래색으로 커지고 깜빡인다 |

방향은 캐릭터의 위치에서 재고, 화면에 그려진 시점을 따른다(프레임마다 갱신).

**폭풍 경고.** 나침반 아래의 패널이다.

| 날씨 | 표시 |
|---|---|
| 맑음, 잦아듦 | 없음 |
| 예고 | 주황. `warning` 아이콘, "폭풍이 다가옵니다", 남은 시간만큼 줄어드는 막대(숫자 없음) |
| 폭풍 | 빨강. `storm` 아이콘, "폭풍". 막대 없음 |

**가장자리 효과와 깜빡임.** 가장자리 효과는 화면 전체의 테두리가 안쪽으로 번지는 색이고, 여러 개가 겹칠 수 있다.

| 조건 | 효과 |
|---|---|
| 폭풍 속 실외 (세기 > 0, 대피 영역 밖) | 가장자리 모래색 |
| 체온이 추움이나 저체온 | 가장자리 푸른색. 체온 막대 깜빡임 |
| 체력 30 이하 | 가장자리 붉은색 |
| 피해를 입는 중 | 체력 막대 깜빡임. 체력 막대의 이름 옆에 원인 아이콘과 이름(폭풍, 추위, 갈증) |
| 갈증 20 이하 | 갈증 막대 깜빡임 |

- 설계의 "폭풍 속 실외에서 체력 막대가 깜빡임"을 "피해를 입는 중이면 깜빡임"으로 넓혔다. 추위와 갈증으로 체력이 줄 때도 같아야 하기 때문이다.
- 피해 원인 표시는 피해가 멈춘 뒤 1초 동안 남는다.
- 깜빡임은 1초에 한 번이다. 색에만 의존하지 않도록 원인은 아이콘과 글자로, 단계는 글자로 함께 적는다.
- 체력, 체온, 갈증의 이름 앞과 대피 중 표시에 아이콘을 붙인다.

### 조준점과 상호작용 안내 (2.12)

어느 대상을 고르는지는 시제품 설계 3.5의 규칙을 따른다. 여기서는 화면에 무엇이 나오는지만 정한다. 무엇을 보여 줄지는 다른 HUD 요소처럼 `src/ui/hudState.ts`가 정한다. 크기와 색은 초기값이다.

| 요소 | 내용 |
|---|---|
| 조준점 | 화면 한가운데의 작은 점. 플레이 중에는 늘 보인다. 대상이 있으면 조금 커지고 밝아진다. 풍경을 가리지 않게 평소에는 반쯤 투명하다 |
| 상호작용 안내 | 조준점 아래에 키와 동작을 한 줄로 표시. 대상이 있을 때만 나온다. 상자는 `[E] 수색 (누르고 있기)`, 영어는 `[E] Search (hold)`. 키는 네모 안에 넣어 글자와 구분한다 |
| 진행 고리 | 조준점 둘레의 고리. 0~1의 값을 받아 위에서부터 시계 방향으로 찬다. 0이면 보이지 않는다 |

- 안내 문구는 대상이 할 수 있는 일의 종류마다 하나씩 문구 파일에 둔다(`interact.search` 등). 키 이름과 문장을 이어 붙이지 않고 `{key}`로 끼워 넣는다.
- 창이 열려 있거나 쓰러져 있는 동안에는 조준점과 안내를 모두 숨긴다.
- 조준점은 대상을 고르는 기준이 아니다. 대상은 캐릭터와의 거리와 시점의 수평 방향으로 고르므로(시제품 설계 3.5), 카메라를 멀리 빼거나 위에서 내려다봐도 같은 대상이 잡힌다.
- 2.12에서는 진행 고리의 모양과 값을 받는 부분만 만든다. 견본 창(F4)에 고리의 견본을 따로 넣어 차는 모습을 확인한다(창이 열려 있는 동안 HUD의 조준점은 숨기 때문이다). E를 누르는 동안 고리가 차는 것은 2.14에서 붙인다.

### 빠른 사용 칸과 가방 표시 (2.13, 2.15)

화면 아래 가운데의 칸은 가방이 아니라 **빠른 사용 칸**이다. 가방을 열지 않고 숫자 키로 물건을 쓰기 위한 것이다. 가방 속은 가방 창(7장)에서 본다. 규칙은 시제품 설계 4.4(가방)와 4.5(빠른 사용 칸)에 있다. 크기와 색은 초기값이다.

**빠른 사용 칸** (2.15에서 만든다)

| 요소 | 내용 |
|---|---|
| 칸 | 4개를 한 줄로. 왼쪽 위에 누르는 키(1~4) |
| 지정된 칸 | 물건의 아이콘, 짧은 이름, 오른쪽 위에 가방에 든 개수(가방의 모든 칸을 합친 수) |
| 가방에서 다 없어졌을 때 | 마지막 하나를 쓰거나 버리면 칸이 빈다(지정되지 않은 칸의 모양으로 돌아간다). 0개인 칸은 없다. 2.15의 직접 확인에서 정했다 |
| 지정되지 않은 칸 | 키 번호만 있는 어두운 칸. 처음에는 네 칸이 모두 이렇다 |
| 크기와 자리 | 가방 창의 칸과 같은 크기(한 변 4.3em). 화면 아래 가운데, 체력 막대와 "대피 중" 표시 사이 |
| 쓸 때 | 누른 칸이 잠깐 밝아진다. 쓸 수 없으면(빈 칸, 이미 가득 찬 수치) 칸이 잠깐 흔들리고 아무것도 줄지 않는다 |
| 강조 | 갈증이 20 이하이고 물병이 있으면 물병의 칸이, 체력이 30 이하이고 붕대가 있으면 붕대의 칸이 깜빡인다. 지정하지 않았으면 강조할 칸이 없다 |

- 칸은 물건을 담는 곳이 아니라 **가방 속의 물건을 가리키는 표시**다. 칸에 지정해도 가방의 자리는 그대로 차지하고, 가방의 8칸 제한도 그대로다.
- **지정할 수 있는 것은 쓸 수 있는 물건과 무기뿐이다.** 쓸 수 있는 물건은 누르면 쓰고, 무기는 누르면 바꿔 든다. 시제품에는 무기가 없어 물병과 붕대만 지정된다. 수리 재료는 지정할 수 없다.
- 처음에는 아무것도 지정되어 있지 않다. 가방 창에서 물건을 고르고 숫자 키를 눌러 지정하고, 같은 번호를 다시 누르면 푼다. 그 물건이 다른 칸에 있었으면 두 칸이 맞바뀐다.

**가방 표시** (2.13에서 만든다)

| 요소 | 내용 |
|---|---|
| 모양 | `bag` 아이콘, 여는 키 `[Tab]`, 찬 칸 수 `6 / 8` |
| 가득 참 | 빈 칸이 없으면 주황색. 물건을 넣지 못했을 때 잠깐 흔들린다 |
| 넣었을 때 | 든 물건의 수가 바뀌는 순간 잠깐 밝아진다(같은 칸에 겹쳐 들어가 찬 칸 수가 그대로여도). 가방을 열지 않아도 주운 것이 들어갔음을 알 수 있다 |

- 무엇을 그릴지는 `hudState.ts`가 정하고 HUD는 바뀐 것만 다시 그린다.

### 폭풍 경고에 남은 시간을 보여 줄 것인가
원칙 1(풍경이 먼저)과 충돌할 수 있는 부분이다. 예고가 30초로 짧아진 만큼 **줄어드는 막대는 보여 주되 숫자는 쓰지 않는 것**으로 정했다. 플레이 테스트에서 사람들이 막대만 보고 풍경을 보지 않으면 막대를 없애는 것을 검토한다.

## 6. 상자 패널

상자를 다 열면 뜬다. 규칙은 시제품 설계 4.6에 있다.

```
                                             +-------------------------------+
                                             | CAR TRUNK                     |
                                             |-------------------------------|
                                             | > Scrap            x2         |
                                             |   Water bottle     x1         |
                                             |   Tape             x1         |
                                             |-------------------------------|
                                             | [E] Take   [F] Take all       |
                                             | Bag 6 / 8        [Esc] Close  |
                                             +-------------------------------+
```

| 요소 | 내용 |
|---|---|
| 자리 | 화면의 오른쪽 위. 가방 창이 열려 있으면 그 왼쪽에 나란히 선다. 캐릭터와 다가오는 폭풍이 가려지지 않는다 |
| 제목 | 상자 종류(차량 트렁크, 수납장, 상자) |
| 물건 목록 | 한 줄에 아이콘, 이름, 개수. 화살표 키(위, 아래)나 휠, 마우스로 고른다. 처음에는 첫 줄이 골라져 있다 |
| 가져가기 | E 키나 버튼. 고른 줄의 묶음을 가방에 넣는다. 줄을 마우스로 두 번 눌러도 된다 |
| 모두 가져가기 | F 키나 버튼 |
| 가방 상태 | 찬 칸 수. 빈 칸이 없으면 주황색 |
| 못 넣는 물건 | 가방에 자리가 없는 물건의 줄은 흐리게 하고, 아래에 "가방이 가득 찼습니다"라고 적는다 |

- 상자에서 2m 넘게 멀어지거나 Esc를 누르면 닫힌다. 다 가져가면 자동으로 닫힌다.
- 패널을 연 채로 WASD로 걷고 Space로 점프할 수 있다(가방 창과 같다). 시점도 그대로 돌릴 수 있다. 휠은 카메라 거리 대신 물건 선택에 쓴다.
- 수색하느라 누르고 있던 E는 패널이 뜬 뒤에 "가져가기"로 치지 않는다. 뗐다가 다시 눌러야 한다.
- 빈 상자는 패널을 띄우지 않는다. 조준점 아래의 안내가 "비어 있음"으로 바뀐다.

**가방 창과 함께 열려 있을 때.** 가방을 연 채로 상자를 수색할 수 있고, 상자 패널을 연 채로 Tab으로 가방을 열 수 있다. 두 창이 나란히 서고(왼쪽이 상자, 오른쪽이 가방) 키를 나눠 쓴다. 가방이 차서 못 넣을 때 가방을 따로 열지 않고 버리고 가져가기 위한 것이다.

| 키 | 하는 일 |
|---|---|
| 위, 아래 화살표와 휠 | 상자 패널의 줄 고르기 |
| 왼쪽, 오른쪽 화살표 | 가방의 칸 고르기. 8칸을 한 줄로 보고 차례로 넘어간다 |
| E, F | 상자에서 가져가기, 모두 가져가기 |
| X | 가방의 고른 칸에서 하나 버리기 |
| Enter, 1 ~ 4 | 가방의 고른 물건 쓰기, 빠른 사용 칸에 지정 (2.15) |
| Tab | 가방 창만 열고 닫기 |
| Esc | 상자 패널을 먼저 닫고, 한 번 더 누르면 가방 창을 닫는다 |

**조준점 아래의 안내** (5장의 상호작용 안내에 더해지는 것)

| 상자의 상태 | 안내 |
|---|---|
| 아직 열지 않음 | `[E] 수색 (누르고 있기)`. 누르는 동안 고리가 찬다 |
| 열었고 물건이 남음 | `[E] 열기` |
| 열었고 비어 있음 | `비어 있음` (키 없음) |
| 버린 물건의 더미 (시제품 설계 4.7) | `[E] 줍기`. 한 번 누르면 들어가는 만큼 가방에 넣는다 |
| 떨어뜨린 가방 (시제품 설계 2.4) | `[E] 가방 되찾기`. 더미보다 크고 주황색이다. 지금 구역에 있으면 나침반에 `marker-bag` 아이콘으로 방향이 나온다(대피소 표시와 같은 방식. 주황색) |
| 대피소의 문 (시제품 설계 2.1) | `문 수리: 고철 12/15, 천 5/8, 테이프 1/3`. 수리를 마치면 `수리를 마친 문`. 키가 없다: 알려 주기만 한다 |
| 구역의 출입구 (시제품 설계 5.5) | 강바닥의 덮개는 `[E] 대피소로 내려가기`, 대피소의 사다리는 `[E] 밖으로 나가기`. 한 번 누르면 구역이 바뀐다. 안내는 가는 구역마다 하나씩 문구 파일에 둔다(`interact.travel_구역ID`) |
| 패널이 열려 있음 | 안내와 조준점을 숨긴다 |

## 7. 가방 창

Tab으로 열고 닫는다. 커서가 나타나고 게임은 계속 흐른다. 가방 속을 보는 곳은 여기뿐이다(HUD에는 찬 칸 수만 나온다).

```
            +----------------------------------------------------+
            | BAG                                        6 / 8   |
            |----------------------------------------------------|
            | [Scrap 5] [Scrap 1] [Cloth 3] [Tape  1]            |
            | [Water 2]1[Band  1]2[       ] [       ]            |
            |----------------------------------------------------|
            | Water bottle                         Quick slot 1  |
            | Restores thirst.                                   |
            |         [Enter] Use   [X] Discard   [Tab] Close    |
            | 1-4: assign to a quick slot (again to clear)       |
            +----------------------------------------------------+
```

| 요소 | 내용 |
|---|---|
| 칸 8개 | 4칸씩 두 줄. 가방의 칸 순서 그대로다. 화살표 키나 마우스로 고른다. 처음에는 첫 칸이 골라져 있다 |
| 칸의 내용 | 아이콘, 짧은 이름, 개수. 빠른 사용 칸에 지정된 물건에는 그 번호를 붙인다 |
| 고른 물건 | 아래에 이름과 설명. 빠른 사용 칸에 지정되어 있으면 그 번호 |
| 사용 | Enter 키나 버튼으로, 고른 칸의 물건을 하나 쓴다. 물병과 붕대만 가능. 수리 재료는 버튼이 비활성화되고 "대피소로 가져가면 수리에 쓰입니다"라고 표시. 채울 것이 없으면(갈증 100에서 물병, 체력 100에서 붕대) 버튼이 비활성화되고 "지금은 쓸 필요가 없습니다"라고 표시. 누르고 있어도 한 번만 쓴다 (2.15) |
| 버리기 | X 키나 버튼으로, 고른 칸에서 한 개씩 버린다. 누르고 있어도 한 번만 버린다. 빈 칸을 고르면 버튼이 비활성화된다(흐려지고 테두리가 점선이 된다). 버린 물건은 발밑에 놓이고 다시 주울 수 있다(시제품 설계 4.7, 2.15) |
| 빠른 사용 칸 지정 | 쓸 수 있는 물건을 고른 채 1~4를 누르면 그 칸에 지정된다. 지정된 칸의 번호를 다시 누르면 풀린다. 수리 재료를 고른 채 누르면 "빠른 사용 칸에는 쓸 수 있는 물건만 넣을 수 있습니다"라고 표시. 빈 칸을 고른 채 누르면 아무 일도 없다. 창이 열려 있는 동안 숫자 키는 물건을 쓰지 않는다 (2.15) |

- **화면의 오른쪽 위에 작게 띄운다**(시각 표시 아래). 처음에는 가운데에 띄웠는데 캐릭터를 가려서 옮겼다(2.13의 직접 확인). 캐릭터와 다가오는 폭풍이 보여야 하기 때문이다. 위의 그림은 창의 구성만 보여 준다.
- 창이 열려 있어도 시간과 폭풍은 흐르고, WASD로 걷고 Space로 점프할 수 있다(폭풍이 오면 가방을 연 채로도 달아날 수 있어야 한다). 창이 쓰는 키(화살표, X, Tab, Esc, 2.15부터 숫자 키)와 Enter는 게임에 넘어가지 않는다.
- 타이틀 화면이 떠 있거나 쓰러져 있는 동안에는 열리지 않는다. 화면 가운데에 다른 창(알림 등)이 떠 있을 때도 열리지 않는다. 상자 패널과는 함께 열린다(6장).
- 가방 창만 열려 있을 때는 조준점과 상호작용 안내를 숨기지 않는다. 가방을 연 채로 상자에 다가가 수색할 수 있어야 하기 때문이다.
- 가방이 바뀌면(다른 플레이어나 게임이 바꿔도) 열려 있는 창에 바로 반영된다.
- 빈 가방도 열 수 있다. 칸이 모두 비어 있고 "가방이 비어 있습니다"라고 나온다.
- **사용 키는 Enter다.** 처음 그림에는 E였는데, E는 가방을 연 채로 상자를 수색하고 버린 물건을 줍는 데 써야 해서 바꿨다(2.15). 상자 패널이 함께 열려 있어도 Enter는 가방의 것이다.
- 2.13에서 보기와 버리기를 만들었고, 2.15에서 사용과 빠른 사용 칸 지정을 더했다.

## 8. 귀환 정산

대피소에 들어오면 나온다. 이때는 게임 시간이 멈춘다(대피소 안은 안전하다).

```
+------------------------------------------------------------------------------+
|                                                                              |
|                            DAY 2  -  RETURNED                                |
|                                                                              |
|     BROUGHT BACK                        DOOR REPAIR                          |
|     Scrap           x6                  Scrap   [#######---]  12 / 15  (+6)  |
|     Cloth           x2                  Cloth   [#####-----]   5 / 8   (+2)  |
|     Water bottle    x1                  Tape    [###-------]   1 / 3         |
|                                                                              |
|                                         Health  +50                          |
|                                                                              |
|                           [   NEXT DAY   ]                                   |
|                                                                              |
+------------------------------------------------------------------------------+
```

| 요소 | 내용 |
|---|---|
| 제목 | 며칠째인지 |
| 가져온 물건 | 이번 원정에서 얻은 것 |
| 수리 진행도 | 재료별 막대. 이번에 늘어난 만큼을 다른 색으로 표시하고 차오르는 움직임을 줌 |
| 회복 | 체력 회복량 |
| 다음 날 | 누르면 다음 날 아침 대피소에서 시작 |

이 화면이 시제품의 **보상 장면**이다. 막대가 차오르는 것이 "한 번 더"의 동기가 되어야 하므로, 다른 화면보다 움직임과 소리에 공을 들인다.

첫 귀환(도입부 직후)에는 수리 목표를 설명하는 한 줄이 추가된다.

**2.17에서 만든 것.** 규칙은 시제품 설계 2.3에 있다.

- 화면 가운데의 창이다. 제목(`N일째 - 귀환`), 가져온 물건의 목록(아이콘, 이름, 개수. 없으면 "이번에는 가져온 것이 없습니다"), 아래에 실제로 회복된 체력(`체력 +50`)과 생존 일수(`생존 N일`), "다음 날" 버튼.
- 구역 전환의 화면이 다 밝아진 뒤에 뜬다. 처음에는 밝아지는 도중에 떠서 구역 이름과 겹쳤다.
- 버튼, Enter, Esc 모두 "다음 날"이다. 다른 선택은 없다.
- 떠 있는 동안 캐릭터는 움직이지 않고 가방 창은 열리지 않으며 게임 시간이 멈춘다.

**2.18에서 더한 것.** 규칙은 시제품 설계 2.1에 있다.

- 창을 그림처럼 두 칸으로 넓혔다: 왼쪽에 가져온 물건, 오른쪽에 문 수리.
- 문 수리의 줄: 재료의 아이콘과 짧은 이름, 막대, `모은 수 / 필요한 수`, 이번에 들어간 만큼 `(+N)`.
- 막대는 전부터 들어 있던 만큼(모래색)과 이번에 들어간 만큼(노란색)으로 나뉜다. 이번 것은 창이 뜬 뒤 0에서부터 0.9초에 걸쳐 차오른다. 필요한 수를 채운 줄은 초록색이 된다.
- 세 재료를 모두 채우면 줄 아래에 "문 수리를 마쳤습니다."가 나온다. 끝 화면은 2.24에서 만든다.
- 정산의 소리는 아직 없다(소리를 다루는 단계에서 더한다).

## 9. 사망

```
+------------------------------------------------------------------------------+
|                                                                              |
|                               YOU DIED                                       |
|                         Caught in the storm.                                 |
|                                                                              |
|              Your bag was left where you fell.                               |
|              Return there to recover it.                                     |
|                                                                              |
|                          [   CONTINUE    ]                                   |
|                          [ QUIT TO TITLE ]                                   |
|                                                                              |
+------------------------------------------------------------------------------+
```

| 요소 | 내용 |
|---|---|
| 사망 원인 | 폭풍, 추위, 갈증 중 하나 |
| 가방 안내 | 떨어뜨린 곳에 가면 되찾을 수 있다는 것. 가방이 비어 있었으면 이 문구는 없음. 전에 떨어뜨린 가방이 아직 남아 있으면 "전에 떨어뜨린 가방은 사라집니다."를 한 줄 더한다 (2.20) |
| 계속하기 | 다음 날 아침 대피소에서 시작. 나침반에 가방 위치가 표시됨. 처음 골라져 있는 버튼이고, Esc로 창을 닫아도 이것으로 친다 |
| 그만하기 | 타이틀 화면으로 돌아간다. 다시 시작하면 처음부터다 |

체력이 0이 되면 캐릭터가 쓰러지고, 그 1.5초 동안 화면이 서서히 어두워진 뒤 창이 나타난다. 창 뒤로 쓰러진 캐릭터와 폭풍이 계속 보인다. 벌을 주는 느낌보다 "다시 해 보자"가 되도록 문구를 짧고 담담하게 쓴다.

## 10. 일시정지

Esc로 연다. 게임 시간이 멈추고 화면이 어두워진다.

```
                        +------------------------------+
                        |           PAUSED             |
                        |------------------------------|
                        |        [  Resume   ]         |
                        |        [  Settings ]         |
                        |        [  Controls ]         |
                        |        [  Restart  ]         |
                        +------------------------------+
```

| 버튼 | 내용 |
|---|---|
| 계속하기 | 게임으로 돌아감. Esc로도 됨 |
| 설정 | 설정 화면으로 |
| 조작 방법 | 키 배치 그림 |
| 처음부터 | 확인을 받은 뒤 타이틀로. 시제품에는 저장이 없으므로 진행이 사라진다고 알림 |

창이 가려지면(다른 창으로 전환 등) 자동으로 이 화면이 뜬다.

**2.21에서 만든 것**

- 열린 창이 없을 때만 Esc가 일시정지다. 가방이나 상자 패널이 열려 있으면 Esc는 그 창을 닫는다.
- 일시정지 중에는 게임이 통째로 멈춘다(시계, 날씨, 갈증, 이동). 마우스를 움직여도 시점이 돌지 않는다.
- 조작 방법은 그림 대신 표로 보여 준다: 왼쪽에 동작, 오른쪽에 키(네모로 그린다). 뒤로나 Esc로 일시정지 창에 돌아온다.
- 처음부터는 확인 창을 거친다. 첫 버튼이 "뒤로"여서 Enter를 급히 눌러도 진행을 잃지 않는다.
- 브라우저 창이 포커스를 잃거나 탭이 가려지면 일시정지된다. 옆에 가방 창이 열려 있어도 그렇다. 가운데에 창(정산, 사망 알림)이 떠 있을 때는 그 창이 그대로 남는다.
- 설정 버튼은 2.22에서, 의견 남기기는 2.24에서 더한다.

## 11. 설정

타이틀과 일시정지에서 들어온다. 항목은 [시제품 설계](06-시제품설계.md) 7장에 있다.

```
            +----------------------------------------------------+
            | SETTINGS                                           |
            |----------------------------------------------------|
            | CONTROLS                                           |
            |   Mouse sensitivity      [-------|-------]         |
            |   Invert Y               [ Off ]                   |
            | SOUND                                              |
            |   Master volume          [-----------|---]  80%    |
            | DISPLAY                                            |
            |   Graphics quality       [ Low | HIGH ]            |
            |   Fullscreen             [ Off ]                   |
            |   Show FPS               [ Off ]                   |
            | OTHER                                              |
            |   Language               [ ENGLISH | Korean ]      |
            |----------------------------------------------------|
            | [ Reset to defaults ]                    [ Back ]  |
            +----------------------------------------------------+
```

- 시제품은 항목이 적어서 한 화면에 모두 보여 준다. 본편에서 항목이 늘면 분류별 탭으로 나눈다.
- 바꾸는 즉시 적용한다. 감도는 창 뒤의 게임 화면에서 바로 확인할 수는 없으므로(일시정지 상태), 값 옆에 숫자를 보여 준다.
- 음량을 움직이면 짧은 소리로 크기를 들려준다.
- 뒤로를 누르면 들어온 곳(타이틀 또는 일시정지)으로 돌아간다.

**2.22에서 만든 것**

- 아래의 버튼은 위에서부터 뒤로, 기본값으로 되돌리기다. 뒤로가 처음 골라져 있어 Enter로 바로 나간다. Esc도 뒤로다.
- 감도와 음량의 슬라이더는 마우스로 움직인다(창의 화살표 키는 아래 버튼 사이를 옮긴다). 고르는 항목은 버튼을 눌러 바꾼다.
- 감도는 0.25~2.50의 배수로 보여 준다(1.00이 기본). 음량은 퍼센트다.
- 음량을 움직일 때의 확인음은 아직 없다(바람 소리의 크기가 바로 바뀌는 것으로 확인한다).
- 전체 화면은 브라우저가 거부할 수 있다. 그때는 아무 일도 일어나지 않고 표시도 "끄기"로 남는다.
- 언어는 주소의 `?lang`(이번 접속만), 설정에서 고른 것, 브라우저 언어의 순서로 정해진다. 타이틀의 언어 버튼도 설정을 바꾼다.
- FPS 표시는 HUD의 왼쪽 위에 `60 FPS`처럼 나온다.

## 12. 끝 화면

문 수리를 마치면 나온다.

```
+------------------------------------------------------------------------------+
|                                                                              |
|                         THE SHELTER IS SEALED                                |
|                     Thanks for playing the prototype.                        |
|                                                                              |
|                 Time played        12:40                                     |
|                 Days survived      4                                         |
|                 Deaths             1                                         |
|                                                                              |
|          [   LEAVE FEEDBACK   ]        [   KEEP PLAYING   ]                  |
|                                                                              |
|                 This is an early prototype. Your feedback                    |
|                 decides what gets built next.                                |
+------------------------------------------------------------------------------+
```

| 요소 | 내용 |
|---|---|
| 완료 문구 | 목표를 달성했다는 것과 시제품이 여기까지라는 것 |
| 플레이 요약 | 걸린 시간, 생존 일수, 사망 횟수 |
| 의견 남기기 | 외부 설문을 새 탭으로 엶. 두 버튼 중 더 눈에 띄게 |
| 계속하기 | 목표 없이 계속 플레이 |

의견 남기기는 일시정지 화면에도 작게 넣어, 끝까지 가지 않은 사람도 의견을 줄 수 있게 한다.
